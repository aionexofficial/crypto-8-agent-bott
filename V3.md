Existing Streamlit app.py stays unchanged. V3 requires a Linux host with Docker Compose and persistent volume. Set PANEL_PASSWORD in a private environment, then docker compose up -d --build. Access panel via authenticated HTTPS reverse proxy or private VPN; port is bound to localhost by default. Do not expose raw HTTP. Worker starts STOPPED; emergency latch survives restarts, reset leaves STOPPED. SQLite transaction checks generation before simulated fills; a stop invalidates in-flight scans. Single worker lock. Back up volume. No real orders. Solana observation only. Five pairs; simulated pre-positioned inventory, assumed 0.1% fees, no rebalancing or real execution.
